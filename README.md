# EE Tube 0.2 — Android media downloader

**الحالة:** مصدر برمجي قابل للبناء عبر GitHub Actions، لم يُختبر على جهاز حقيقي. ليس نسخة كاملة من Snaptube ولا يحتوي على كود/شعارات منه.

## وظائف هذا الإصدار

- واجهة عربية بأربعة أقسام: الرئيسية، المتصفح، التنزيلات، الإعدادات.
- شريط بحث يُحوِّل النص إلى بحث ويب، ويفتح روابط HTTP/HTTPS.
- اختصارات لمواقع فيديو مع التنبيه إلى أن **وجود الاختصار لا يعني نجاح تنزيل فيديوهات الموقع**.
- متصفح WebView مع تنقل، تحديث، حفظ مواقع مفضلة وسجل تصفح محلي.
- اكتشاف روابط الفيديو والصوت التي يوفرها الموقع مباشرة عبر عناصر HTML5 وطلبات المتصفح.
- تنزيل الملفات المباشرة باستخدام Android DownloadManager في الخلفية، مع سجل للتنزيلات.
- دعم أولي لتنزيل **HLS غير المشفر بشرط أن تكون قائمة VOD مكتملة ومقاطعها MPEG-TS (`.ts`)**، مع عرض الجودات من master playlist، وتنزيل foreground وإشعارات تقدّم وزر إلغاء. يُحفظ الناتج بصيغة `.ts` في Downloads/EE Tube. لا يدعم استئناف HLS بعد موت العملية. قد تحتاج مشغّلًا يدعم TS.
- حفظ ملفات MP3/M4A الأصلية المتاحة مباشرة. **لا يحوّل الفيديو إلى MP3**.

## قيود مهمة

لا يدعم التطبيق حاليًا تنزيل الفيديوهات المحمية بـDRM، تجاوز CAPTCHA، استخراج التواقيع الخاصة للمواقع، تنزيل DASH، HLS مشفر أو fMP4، أو تنزيل فيديوهات من كل خدمات التواصل. بعض مواقع YouTube/TikTok/Facebook/Instagram قد تفتح في المتصفح دون أن تسمح بالتنزيل. عمليات HLS التي تعتمد على روابط مؤقتة أو مسارات صوت منفصلة قد تفشل.

**حجم APK ليس مقياسًا للتكامل.** لأن المشروع يعتمد على Android SDK ولا يضم FFmpeg أو محركات استخراج خدمات متعددة، فقد يكون حجمه أقل من 2MB.

## البناء

GitHub Actions: `.github/workflows/android.yml` — Java 17، Gradle 8.9، Android SDK 35، AGP 8.7.3. عند نجاح workflow ينشأ artifact باسم `EE-Downloader-debug-APK` يحوي `ee-downloader-debug.apk`.

### رفع النسخة 0.2 عبر Termux

1. نزّل ملف `ee-tube-v02.zip` من المحادثة إلى Downloads.
2. افتح Termux وتأكد من منح صلاحية التخزين مسبقًا.
3. نفّذ:

```bash
cd ~/storage/downloads
unzip -o ee-tube-v02.zip -d "$HOME"
bash ~/ee-tube-v02/UPDATE_TERMUX.sh
```

السكربت يحدث المجلد الذي رفعته سابقًا `~/ee-downloader` دون إزالة تاريخه، ويوقف نفسه لو فيه تعديلات غير محفوظة. ثم يرفع commit جديد ويشغّل البناء تلقائيًا. **الرفع يتطلب صلاحية كتابة GitHub من جهازك**؛ موصل ChatGPT المتاح قراءته فقط.

## الخطة المقبلة

- تقوية محرك HLS لدعم fMP4 والصوت المنفصل ثم تنزيلات قابلة للاستئناف.
- دعم محرك استخراج المواقع عبر موصلات مستقلة يمكن تحديثها بأمان.
- تحويل الصوت محليًا إلى M4A أو MP3 وفق المكتبات والقيود القانونية المناسبة.
- تحسينات Fold4/tablet، اختبارات UI على محاكي وجهاز حقيقي، واختبارات تنزيل بمصادر يملك المستخدم حقوقها.

## الخصوصية

المتصفح والتنزيلات محليان. المواقع المفتوحة داخل WebView تخضع لسياسة الخصوصية الخاصة بها. لا يتضمن الكود خوادم جمع بيانات.
